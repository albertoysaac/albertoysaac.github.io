Este repositorio aloja mi portafolio profesional interactivo, diseñado como una Single Page Application (SPA) moderna y responsiva. El objetivo de este proyecto es demostrar no solo mi trayectoria, sino mis capacidades técnicas en el diseño de interfaces y visualización de datos.

🔗 Ver Portafolio en Vivo (El enlace funcionará una vez configures GitHub Pages)

🛠 Tecnologías Utilizadas

Este portafolio fue construido con un enfoque en rendimiento (Performance-First) y limpieza de código:

HTML5 Semántico: Estructura accesible y optimizada para SEO.

Tailwind CSS (CDN): Para un diseño responsivo, utilitario y moderno sin hojas de estilo pesadas.

JavaScript (ES6+): Lógica del lado del cliente para interactividad y manejo del DOM.

Chart.js: Visualización de datos (Gráfico de Radar para habilidades y métricas).

FontAwesome / Unicode: Iconografía ligera.

✨ Características Principales

Dashboard de Métricas: Visualización de "Soft & Hard Skills" mediante gráficos de radar interactivos.

Línea de Tiempo Dinámica: Historia laboral navegable sin recargas de página.

Matriz de Proyectos: Grid responsivo para mostrar trabajos recientes con detalles técnicos al hacer hover/click.

Diseño Adaptativo: Experiencia fluida desde móviles hasta pantallas de escritorio.

Modo Auditoría: Estructurado para que los reclutadores encuentren métricas de impacto (ej. "30% optimización") rápidamente.
